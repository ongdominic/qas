# Conventions

- Dates: ISO `YYYY-MM-DD`, times in SGT 24h `HHmm`.
- Capture filenames: `YYYY-MM-DD HHmm short-title.md` in `00 Inbox/`.
- Project folders: kebab-case slugs, e.g. `10 Projects/yi-hui-metals/`.
- Frontmatter on filed notes: `created`, `source`, `project` or `area`, `tags`.
- Log entries: see root `CLAUDE.md`. Brief: current snapshot only, ≤1 page.
- Money: state currency every time (SGD, USD).
- Nothing is deleted; it moves to `40 Archive/`.
